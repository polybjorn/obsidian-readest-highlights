# Security policy

Please use GitHub's [private vulnerability reporting](https://github.com/polybjorn/obsidian-readest-highlights/security/advisories/new) rather than opening a public issue. This keeps the disclosure private until a fix is available. You can also email security@polybjorn.com, encrypted with the key at https://polybjorn.com/pubkey.asc if the report holds anything sensitive.

Expect an initial response within a week. Only the latest released version receives fixes.
